# 崙背國中課表

公開免登入的教師與班級課表查詢網站，適用電腦與手機。

- 上方選班級，下方選老師；選定後顯示課表並收起教師名單。
- 點班級課程可查看授課老師課表及該節調課候選，並可返回原班級，保留星期與顯示模式。
- 手機預設單日列表，可切換整週課表；電腦顯示整週。
- 點選課程可查同班直接互換候選，雙方交換後均不得衝堂。
- 第 1–7 節彼此互調，第 8 節僅與第 8 節互調。
- 「待補課表」不能查詢；「部分課表」保留已知課程，未知時段顯示「未提供」，不提供調課候選。

資料版本為 115.09.04，適用期間為 2026-08-31 至 2027-01-29。候選只依固定課表判斷，仍須向對方確認臨時調課、其他行程與在校時間。

此專案使用純 HTML、CSS、JavaScript，可直接由 GitHub Pages 的 `main` 分支根目錄發佈。無需後端、帳號或套件安裝。

更新資料後執行：

```sh
python3 build-data.py
node swap-engine.cjs
```

本機預覽可在專案根目錄執行 `python3 -m http.server 8766`，再以瀏覽器開啟對應的本機網址。
